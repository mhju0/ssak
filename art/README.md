# Ssak visual archive

The final interface is the Korean hanji pressed-flower album. Portfolio assets and
reference renders were checked against the current source on 2026-09-05 using Xcode 26.6.

| Asset | Provenance |
|---|---|
| [hero.png](hero.png) | Final windowsill view, rendered headlessly from SwiftUI; not a device photograph. |
| [social-preview.png](social-preview.png) | 1280 × 640 portfolio card composed directly in `SsakAppRender` from the final UI and text. |
| [walkthrough.gif](walkthrough.gif) | Original iOS 26.5 simulator recording: seed picker, planting, watering tutorial, empty shelf. Still matches the final UI. |
| [App icon](appicon/appicon-1024.png) | Original authored icon; identical to the app asset catalog image. |
| [App reference screens](../SsakApp/rendered/) | Final day/dusk/night windowsill, dry/nursing/overwater states, empty/pressable/partial/complete shelf, guide steps, seed and bloom share cards. `ssakmark_variants.png` is an icon study. |
| [Species reference sheets](../SsakArt/rendered/) | Six species across five stages; `marigold_bloom_portrait.png` is the historical art-harness portrait, not the final app share card. |
| [Historical mockups](../docs/design/) | Earlier design studies, retained as history rather than current screenshots. |

Regenerate from the repository root:

```sh
(cd SsakArt && swift run SsakArtRender)
(cd SsakApp && swift run SsakAppRender)
cp SsakApp/rendered/hero.png art/hero.png
cp SsakApp/rendered/social-preview.png art/social-preview.png
```

The harness also emits historical backdrop studies and individual species images; these
are reproducible local outputs and remain ignored. Curated references are whitelisted in
each package's `.gitignore`. Rendering can vary across SDKs and fonts; use a same-machine
baseline for comparisons. The walkthrough is a recording and is not regenerated by these commands.

GitHub's social-preview setting is a separate upload of `social-preview.png`; committing
the image alone does not update that setting.
