# Ssak (싹)

Cozy iOS game — raise one flower from seed to bloom on the real clock, six species to
collect. 100% Swift/SwiftUI, three SwiftPM packages, no backend, no dependencies.

**This project is finished and archived.** The GitHub repo is read-only; pushes are
rejected. Default to reading, explaining, and extracting — not adding features. Anything
else needs the repo un-archived and an explicit go-ahead.

## Where truth lives, in order

1. Current source code and tests
2. Current git state and history
3. `docs/DECISIONS.md` — why things are the way they are, incl. what was reversed
4. `docs/ROADMAP.md` — what is and isn't planned, incl. what was explicitly rejected
5. `docs/PROJECT_HANDOFF.md` — architecture, setup, build/test commands, known defects
6. Historical Claude material (`docs/CLAUDE_ENV_INVENTORY.md`, session transcripts) — only
   when the above is insufficient

Earlier sources win. A doc that disagrees with the code is wrong; fix the doc.

## Keeping the docs honest

- `docs/DECISIONS.md` — when a significant technical or product decision is made or reversed.
- `docs/ROADMAP.md` — when roadmap state materially changes.
- `docs/PROJECT_HANDOFF.md` — only when high-level state or architecture materially changes.

Not a changelog. Routine implementation detail does not belong in any of them.
